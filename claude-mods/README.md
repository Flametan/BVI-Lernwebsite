# Claude-Code-Mods

Zwei eigene Mods für Claude Code, die in jeder Cloud-Sitzung geladen werden (Umgebungsvariable `CLAUDE_CODE_PLUGIN_DIRS` und ein Setup-Skript der Cloud-Umgebung, das diesen Ordner nach `/opt/claude-mods` kopiert).

- `cache-band/`: Leiste über dem Eingabefeld mit Cache-Restzeit, Trefferquote, Kontext-Wetter und Compact-Knopf.
- `prompt-polish/`: Live-Knopf unter dem Eingabefeld, der den eingegebenen Prompt nach Best Practices und den Prompting-Richtlinien von Anthropic verbessert.

Dieser Ordner gehört nicht zur Website und wird nicht veröffentlicht (`_config.yml`).
