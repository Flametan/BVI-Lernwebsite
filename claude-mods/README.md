# Claude-Code-Mods

Eine eigene Mod für Claude Code, die in jeder Cloud-Sitzung geladen wird (Umgebungsvariable `CLAUDE_CODE_PLUGIN_DIRS` und ein Setup-Skript der Cloud-Umgebung, das diesen Ordner nach `/opt/claude-mods` kopiert).

- `cache-band/`: Leiste über dem Eingabefeld mit Cache-Restzeit, Trefferquote, Kontext-Wetter und Compact-Knopf.

Dieser Ordner gehört nicht zur Website und wird nicht veröffentlicht (`_config.yml`).
